Paperkin 1.0 resource provenance — 2026-10-15

Runtime dependencies: UIKit, Foundation, Core Animation, AVFoundation; Apple system frameworks only.
Fonts: system fonts and system serif font design. No bundled third-party fonts.
Icons: Apple SF Symbols through UIImage(systemName:); app icon is original Paperkin artwork.
Creature art: 18 transparent PNGs generated with the built-in imagegen tool, using the approved v2 prototype as a visual reference. Six species each have an ivory locked variant, a partly folded variant, and a completed color variant. Exact prompts, generation source paths and final hashes are retained in artifacts/CFV-Artwork-Prompts.json. These independent illustrations replace the rejected coordinate-authored polygon art. No prototype UI screenshot is bundled. Runtime ImageIO downsampling and a bounded cache preserve the generated alpha and paper details.
Paper/tile artwork: original UIKit paths, procedural paper lines and native shadow layers in CFVVisuals.swift. Leaf, triangle and circle have independent silhouettes; target diamond is separately rendered.
App icon: original complete butterfly rendered at 1024×1024 using the former polygon renderer; retained unchanged by the creature-image revision, opaque PNG, no baked UI text.
Audio: original sine/harmonic synthesis in tools/CFVBuildArtwork.py. Six short effects and a 16-second loop; no samples or external music. Loop frequencies and endpoint envelope are deterministic.
Level content: deterministic offline authoring tool with per-level mechanical constraints; frozen JSON ships in app. No runtime RNG. Exact witnesses in artifacts/validation/CFV-Level-Design-Witnesses.json. Independent production Swift replay validates all solutions.
Prototype images under docs/release-v1/prototypes: planning reference only; not bundled or used as gameplay UI or App Store screenshots.

Developer must review final ownership/copyright statements and store name rights before publication. No third-party license inventory is needed for bundled runtime code because no third-party runtime packages were added.
