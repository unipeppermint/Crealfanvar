Paperkin 1.0 development handoff

Open Crealfanvar.xcodeproj. Use shared scheme Crealfanvar for the app, CFVValidation for UI tests.
The existing app Bundle ID, Debug/Release build settings, signing configuration and iOS 15.0 target have not been changed. A separate UI-test target and shared schemes were added.
The project now uses Git. Generated archives, test results, screenshots, videos and save fixtures are excluded; regenerate them locally when needed. Keep accepted prototypes, source code, resource provenance and level witnesses in source control.

Architecture:
- GameCore/CFVGameCore.swift: UIKit-free tile identity, projection stacks, match union, deterministic turns, terminal outcomes and bounded/cancellable hint search.
- Services/CFVRepository.swift: local catalog and level validation.
- Services/CFVSaveStore.swift: version checks, exact-history replay validation, independent atomic saves and completion reconciliation.
- Features/CFVAppCoordinator.swift: home, level book, collection, detail and completion flows.
- Features/CFVGameController.swift / CFVBoardView.swift: state-driven native board, selection/swipes, crease hit zones, interactive edge folds, previews, commits, undo, hints and interruption handling.
- Features/CFVVisuals.swift: paper texture, shape-distinct tiles and shared, size-aware PNG creature presentation.
- Features/CFVGameAtmosphere.swift: illustrated home stage, chapter routes, collection/reward display, progress ribbons, tactile buttons and finite paper confetti. The scenery JPEG lives in Resources/Scenery; prompt/provenance is in artifacts/CFV-Scenery-Prompt.json.
- Features/CFVSettingsController.swift: settings, paged offline help, privacy/support information.
- Services/CFVSettings.swift: per-app UserDefaults preferences and AVFoundation audio.

Core validation:
  ./tools/CFVRunCoreTests.sh
The test harness compiles the exact production Swift files on macOS. It is deliberately independent of UIKit and does not require a simulator.

UI validation:
  xcodebuild -project Crealfanvar.xcodeproj -scheme CFVValidation \
    -destination 'platform=iOS Simulator,id=YOUR_TEST_DEVICE_ID' \
    -only-testing:CFVUITests/CFVUITests/testFullChineseJourneyAndRecovery \
    CODE_SIGNING_ALLOWED=NO test
Use a dedicated clean simulator for full-journey tests. They preserve app progress, so replaying the same first-install test requires an empty install on that dedicated test device. Release tour and small-layout tests expect the 12-level journey to have been completed through the normal UI on that test device first. No test-only bypass exists inside the app.

Resources:
- 24 frozen level JSON files; runtime never randomizes them. The original 12 still unlock the six collection creatures; the next 12 are advanced challenges.
- 18 imagegen-authored transparent PNG creature stages in Resources/Creatures. Stage 0: ivory locked appearance; stage 1: partially folded; stage 2: completed color artwork. The shared view uses the current stage image for continuous hinged unfolding, avoids crossfading different silhouettes, and respects Reduce Motion.
- 7 generated original audio resources (6 effects + 1 loop).
- English / Simplified Chinese Localizable.strings and InfoPlist.strings.
- AppIcon + PrivacyInfo.xcprivacy.

Authoring scripts are offline developer tools. Do not run CFVBuildLevels.py casually after shipping: any content changes require versioning, validation and save-compatibility review.
Rebuild localization with tools/CFVBuildLocalization.py after copy changes. Keys include the English and Chinese pair to prevent short navigation labels from colliding with long page titles.

Size optimization — 2026-10-15:
- Runtime creature PNGs use a 1152px maximum edge (largest detail view is 380pt at 3x), 256-color palettes and transparent alpha. This is a lossy size optimization; it preserves the existing illustrations and paper texture rather than replacing artwork. All 18 stages were inspected on the app's paper background.
- Creature sources: 23,220,462 -> 5,337,946 bytes. Unsigned Release app: 28,364,699 -> 7,483,401 bytes. These are uncompressed bundle sizes, not App Store download estimates.
- Per-file source/output hashes and settings: artifacts/CFV-Artwork-Optimization.json. The hashes in CFV-Artwork-Prompts.json describe the original generated files, before optimization.
- tools/CFVOptimizeArtwork.cjs is an optional offline authoring tool using sharp/imagequant. It is not an application dependency and is not required to build. Set CFV_SHARP_MODULE to an installed sharp module if it is not on Node's module path. Always provide the original generated PNG directory as input and a separate output directory; never repeatedly compress optimized artwork.
- Size budgets: runtime resources <= 8 MiB, creature art <= 7 MiB, uncompressed Release app <= 12 MiB, individual tracked files and unpublished blobs <= 20 MiB. Reassess deliberately when content grows.
- Removed generated output and obsolete planning archives, original full-resolution PNGs, and a verified complete pre-cleanup Git bundle are temporarily backed up in /private/tmp/CFV-Slim-Backup-20261015. This system temporary directory is not permanent archival storage; retain the original generation files or move the backup to durable storage if needed.
- Previously published Git history is preserved. Only the unpushed animation commit is rewritten to remove large QA files; a normal fast-forward push is sufficient. Local Git recovery objects may still occupy disk space until normal Git maintenance expires them.
