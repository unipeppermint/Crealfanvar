## 页面流程

首页 → 关卡册 → 游戏 → 折叠预览 → 消除与展开 → 游戏或通关。  
通关 → 下一关，或生物详情 → 图鉴。  
游戏 → 暂停 → 设置、帮助、重玩或返回。  
失败 → 撤销上一动作，或重新开始。

首页使用沉浸式封面布局。关卡册和图鉴底部的“首页、关卡、图鉴”是固定导航入口；切换替换当前主页面，不能反复压栈同一页面。游戏、通关和生物详情隐藏这些入口，保留明确返回路径。

## 页面定义

| 编号 | 页面 | 必备信息 | 主操作与返回 |
| --- | --- | --- | --- |
| S01 | 首页 | 当前生物制作阶段、总进度 N/12、图鉴 M/6、设置入口 | 首次“开始折叠”；有存档“继续第 XX 关”；全通关“重温关卡” |
| S02 | 关卡册 | 单页 01–12、完成标记、当前关、锁定条件；提示每两关解锁一种生物 | 点关卡开始；锁定项提示前置关；底部主导航 |
| S03 | 游戏 | 关卡号、目标进度、剩余步数、棋盘、折痕、撤销和提示 | 点选两格或滑动交换；进入折叠预览；返回自动存档 |
| S04 | 折叠预览 | 投影高亮、可消除棋子及目标数、上层纸面提示 | 确认或取消；禁止交换；退出不改状态 |
| S05 | 通关 | 本关结果、使用步数、制作进度、首次解锁奖励 | 下一关；解锁节点显示“查看生物”；第 12 关显示“查看完整图鉴” |
| S06 | 生物图鉴 | 6 张卡片、已解锁数量、每项解锁条件 | 已解锁进入详情，未解锁展示所需关卡 |
| S07 | 生物详情 | 独立插画、名称、短介绍、制作段完成状态 | 播放展开动画、返回图鉴；支持中文和英文 |
| S08 | 暂停 | 继续、重玩、玩法帮助、设置、返回关卡册 | 继续恢复稳定状态；重玩确认清除本局操作 |
| S09 | 失败 | 原因、剩余目标、撤销和重玩 | 有历史时允许撤销；无历史时仅重玩或返回 |
| S10 | 设置 | 音乐、音效、触感、跟随系统或减少动画、帮助、隐私、支持、版本 | 修改立即生效；返回原入口 |
| S11 | 玩法帮助 | 交换、折叠、遮挡、目标标记四张本地说明卡 | 翻页或关闭，不改变当前棋盘 |
| S12 | 存档恢复提示 | 需要重开当前关的原因 | 保留完成进度，重开本关或返回；不静默清除全部数据 |

S01 至 S06 有高保真原型。其余页面是复用面板或详情布局，本节给出实施状态规范；正式开发阶段完成实际页面截图验收。

关卡册使用 3 列×4 行展示全部 12 关，不附加未来章节卡片。三个学习阶段可以用轻量文字标识，但不增加页面或解锁门槛。生物图鉴保持 2 列×3 行，完整保留纸蝶、折翼鸟、纸鱼、纸兔、纸狐、纸鹿，锁定条件依次为完成第 02、04、06、08、10、12 关。

六屏是不同时间点的快照：首页与第 05 关对应总进度 4/12、收藏 2/6；第 06 关通关与图鉴对应总进度 6/12、收藏 3/6。生物插画用于风格预览，正式制作仍按 0/2、1/2、2/2 三个阶段输出素材。

## 游戏布局

以 390×844 pt 作为设计参考，按安全区布局。棋盘为正方形，边长取可用宽度和扣除必要控件后的可用高度中较小者。

- 左右边距以 16 至 20 pt 为起点。
- 6×6 棋盘在 320 pt 宽屏上保持约 48 pt 的格子间距；每格可操作区域至少 44×44 pt。
- 顶部生物插画为可压缩装饰：高度约 56 至 120 pt，小屏优先缩小或隐藏。
- 棋盘和底部工具栏不随背景装饰滚动；关卡册、设置和图鉴可滚动。
- 主要按钮高度至少 48 pt，触控目标至少 44 pt。
- 标题建议 22 至 28 pt，正文 15 至 17 pt，辅助文字不小于 12 pt。
- 开启较大字体时顶部信息允许两行，帮助及设置使用可滚动布局。
- 浅色纸面是首版统一外观；深色系统模式下仍保持同一套可读的纸面主题。

所有尺寸是实现起点，需要在小屏和大字体真机上验收。不可为保留插画而缩小核心棋盘触控区。

## 棋盘反馈

| 状态 | 表现 | 数据变化 |
| --- | --- | --- |
| 可操作 | 棋子、目标菱形和折痕清楚 | 无 |
| 选中棋子 | 深色外框和轻触感 | 无 |
| 无效交换 | 短距离回弹并显示简短原因 | 无 |
| 折叠拖动 | 活动纸片沿折痕转动，目标投影以虚线显示 | 无 |
| 有效预览 | 匹配外框高亮，显示“可消除 X 枚，其中目标 Y 枚” | 无 |
| 无效预览 | 不高亮，禁用确认，说明未形成三连 | 无 |
| 提交结算 | 输入锁定，执行一次消除，折面展开 | 消耗一步，提交新稳定状态 |
| 消除后 | 棋子淡出，纸格留空 | 目标数按唯一棋子计算 |
| 无历史 | 撤销灰显且提供无障碍说明 | 无 |

拖动只是预览方式，不自动扣步。所有提交方式最终进入同一个确认操作，避免手势完成与按钮完成的结果不一致。

建议交换动画约 0.15 至 0.20 秒，折叠约 0.35 至 0.50 秒，消除约 0.20 秒；一轮完整反馈目标不超过约 1.2 秒。减少动画模式以短淡入淡出代替透视旋转，规则和预览内容完全一致。

## 教学与提示

第 01 关用局部遮罩和高亮教学交换。第 02 关提示点击折痕、检查表面、取消预览和确认折叠。第 03 关展示有棋子的上层遮挡下层，第 04 关引导撤销。第 09 关进一步展示空白纸片仍遮挡下层，引导先取消预览再选择操作。

教学绑定关卡中的实际 cellID 和 creaseID，不硬编码屏幕坐标。教学只限制必要的一步，完成后恢复自由操作；可在帮助中重新查看。

提示按钮点击后显示轻量加载状态。先呈现一句方向提示，再由“显示操作”高亮具体格子或折痕。输入变化后取消旧提示，不能把旧棋盘的建议画到新棋盘上。

无解与搜索超时使用不同文案：

- 确认剩余步数内无解：“这条路线无法在剩余步数内完成，试试撤销。”
- 搜索预算用尽：“暂未找到提示，可以继续尝试或撤销。”
- 没有合法动作：“当前没有可用操作，可以撤销或重新开始。”

## 辅助页面和异常状态

暂停面板使用本地文字和按钮，不离开本局。切入后台时结束未提交预览；若动作已提交，则回到其稳定结果。回前台显示暂停态，避免用户错过结果。

重玩确认文案：“重新开始本关？本局操作将清空，已完成关卡和图鉴会保留。”按钮为“取消”和“重新开始”。

覆盖活动存档时明确显示原关卡号。失败页不能出现付费继续、广告复活或随机洗牌。

设置页的支持链接和隐私链接在离线时显示可读的本地说明及链接地址；联网时可由系统浏览器打开。首版核心关卡不依赖外部页面。

存档损坏先尝试备份，再恢复当前关初始状态；完成进度单独存储。若完成进度及其备份也不可读，明确告知受影响内容并保留故障文件，不承诺可以恢复不存在的数据。

## 美术交付清单

| 素材 | 数量基线 | 交付要求 |
| --- | --- | --- |
| 基础棋子 | 3 类 | 透明底、常态图形；选中和高亮由代码绘制 |
| 目标标记 | 1 类 | 独立矢量菱形或代码路径，交换随棋子移动 |
| 纸面材质 | 2 套 | 正面与背面、可拉伸或平铺，无烘焙文字 |
| 生物形象 | 6 种 | 每种 3 个稳定阶段，分别为 0/2、1/2、2/2，共 18 个阶段素材；展开动画需要可分层部件 |
| 生物缩略图 | 6 种 | 可从完整形象导出，锁定态由代码处理 |
| 图标 | 统一一套 | 系统图标优先，折叠图标自行绘制 |
| 背景音乐 | 1 段循环 | 原创或授权，首尾平滑 |
| 音效 | 约 6 类 | 选择、交换、折叠、消除、失败、完成 |
| 应用图标 | 1 套 | 独立纸雕视觉，不直接截取复杂棋盘 |

棋盘图形优先 PDF 矢量或可分辨率导出的透明素材；复杂生物插画可以生成辅助制作，但需检查一致性、透明边缘和使用权。图片生成不代替可交互动画部件制作。

## 易用性验收

图案必须在灰度下仍可区分。选中、目标、合法预览同时有形状或边框提示，不能只靠色差。文字对比以 WCAG 常规正文 4.5:1 作为内部设计目标，并在最终素材上测量。

提供棋盘无障碍元素，朗读行列、图案、目标标记和选中状态；通过“选择”“与相邻格交换”和“预览折痕”动作操作。自定义图层必须有对应的 UIAccessibilityElement，不能只依赖视觉。

VoiceOver 实际操作至少能完成第 01、02、03 关及第 09 关的空白遮挡教学。较大字体、减少动态效果、关闭声音与触感不会阻止通关。
